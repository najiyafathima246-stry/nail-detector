# 🖐️ Kai Onnu Kaattikke! 😂

> **Show your hand! Let Ammachi judge if it's time for a bath! 😭😂**

**Kai Onnu Kaattikke!** is a fun and intentionally humorous AI-powered web application where users can take a picture of their hand or upload an image. The application analyzes the **visible cleanliness of the hand and nails** and provides a funny cleanliness score and verdict.

The main character is **Ammachi 👵**, a funny Kerala grandmother who acts as the virtual judge and gives playful Malayalam voice responses based on the result.

---

## ✨ Features

* 📸 Take a picture using your camera
* 🖼️ Upload a hand image
* 🤖 AI/image-based hand analysis
* 📊 Cleanliness score from 0–100
* 👵 Funny Ammachi character
* 🗣️ Malayalam voice responses
* 😂 Funny clean/dirty reactions
* 🔄 Check Again option
* 📤 Share Result
* 📱 Responsive design
* 🔒 Privacy-focused image handling
* 🎨 Cute, aesthetic and cozy UI

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/kai-onnu-kaattikke.git
```

### 2. Open the project

```bash
cd kai-onnu-kaattikke
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Flask application

```bash
python app.py
```

### 7. Open in your browser

```text
http://127.0.0.1:5000
```

## 🔒 Privacy

The application is designed so that uploaded hand images are **not permanently stored**.

> 🔒 **Your photo is used only for this fun analysis and is not stored.**

---

## ⚠️ Disclaimer

This project is created mainly for **entertainment and educational purposes**.

The application analyzes only **visible characteristics** of a hand image. It cannot detect bacteria, viruses, diseases, infections, or actual medical/hygiene conditions.

The cleanliness score is a **fun AI-generated estimate**, not a scientific measurement.

---

## 🎯 Project Purpose

This project demonstrates how **AI, computer vision, web development, regional language interaction, and creative UI design** can be combined to create an entertaining application.

Instead of creating a traditional AI application, **Kai Onnu Kaattikke!** uses humor and a Malayalam-speaking Ammachi character to make AI more engaging and memorable.
